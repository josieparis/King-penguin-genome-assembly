# 02 — Genome profiling (k = 21)

* `jellyfish_k21.sh` (original) — `jellyfish count -C -m 21 -s 10000000000 -t 8` on the HiFi reads of the first
  SMRT cell, then `jellyfish histo` → `results/Apat.hifi.k21.histo`.
* The histogram was uploaded to **GenomeScope2** (http://genomescope.org/genomescope2.0, k = 21, ploidy 2):
  haploid genome size 1.15 Gb, heterozygosity 0.6 % (Figure S1).
